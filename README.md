# Бот тренировок

Для локального запуска нужны JDK 25, работающий бэкенд Training Collector и собственный Telegram-бот от @BotFather. Скопируйте `.env.example` в `.env` и укажите:

- `BOT_TOKEN` — токен этого Telegram-бота.
- `PLATFORM_URL` — адрес платформы, локально `http://127.0.0.1:8080`.
- `TRAINING_SERVICE_KEY` — ключ, настроенный под этим же именем на платформе.

Запуск — `./gradlew run`, сборка — `./gradlew build`. Gradle читает локальный `.env` для запуска. Переменные процесса имеют приоритет. В продакшене передайте переменные контейнеру и используйте HTTPS или закрытую сеть для доступа к платформе.

```sh
docker build -t training-collector-bot .
docker run --env-file .env training-collector-bot
```

В контейнере задайте `PLATFORM_URL` с доступным из контейнера хостом. Бот работает в режиме long polling, достаточно одного запущенного экземпляра на Telegram-токен.

## Работа с подопечными

В главном меню две кнопки — **Подопечные** и **Упражнения**. Откройте **Подопечные → Добавить подопечного** и введите имя и фамилию двумя сообщениями. Нажмите **Сохранить** или **Редактировать**, чтобы указать вес, рост, возраст, пол, цель, заметки и контакты. При сохранении вес и рост попадут в историю замеров за текущую дату.

В разделе **Упражнения** первая кнопка — **Добавить упражнение**, ниже — личный каталог тренера. Введите название и нажмите **Сохранить** или выберите **Добавить описание**, введите текст и подтвердите сохранение. В карточке видны название и описание. Упражнения с сайта и из бота доступны в одном списке.

В карточке подопечного выберите **Тренировки** или **Замеры**. Раздел **Тренировки** начинается с кнопки **Записать тренировку**, под ней — завершённые тренировки от новой к старой. Новая запись открывается с пустым списком упражнений. Выберите упражнение из своего каталога или добавьте его во время тренировки.

| Выбрано в боте | Сообщение для одного подхода | Результат |
|---|---|---|
| Жим лёжа | `60 10` | 60 кг на 10 повторений |
| Планка | `45с` | 45 секунд без дополнительного веса |
| Удержание гири | `16 30с` | 16 кг в течение 30 секунд |

Несколько подходов можно вставить одним сообщением, каждый с новой строки. Бот создаёт тренировку в PostgreSQL при нажатии **Записать тренировку** и сохраняет принятые подходы сразу. **Готово** заканчивает ввод подходов текущего упражнения. Затем можно добавить ещё одно упражнение или нажать **Завершить тренировку**.

У каждого подопечного может идти одна тренировка. После выхода в меню или перезапуска бота откройте у него **Тренировки** и нажмите **Продолжить тренировку**, чтобы вернуться к тому же шагу, или **Завершить тренировку**, чтобы перенести запись в историю. Затем снова появится **Записать тренировку**. Завершить можно и без подходов. Для исправления результатов выберите тренировку по дате.

В разделе **Замеры** первой идёт кнопка **Добавить новый замер**, под ней — замеры по датам. В форме ввода первые две строки занимают **Сохранить** и **Отмена**, ниже расположены показатели, дата и заметка. При редактировании откроются значения за выбранную дату.
