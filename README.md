# Бот тренировок

Для локального запуска нужны JDK 25, работающий бэкенд Training Collector и собственный Telegram-бот от @BotFather. Скопируйте `.env.example` в `.env` и укажите:

- `BOT_TOKEN` — токен этого Telegram-бота.
- `PLATFORM_URL` — адрес платформы, локально `http://127.0.0.1:8080`.
- `TRAINING_SERVICE_KEY` — ключ, настроенный под этим же именем на платформе.

Запуск — `./gradlew run`, сборка — `./gradlew build`. Gradle читает локальный `.env` для запуска. Переменные процесса имеют приоритет. Все настройки и их значения по умолчанию перечислены в `src/main/resources/bot.conf`.

```sh
docker build -t training-collector-bot .
docker run --env-file .env -e PLATFORM_ALLOW_INSECURE=true training-collector-bot
```

В контейнере задайте `PLATFORM_URL` с доступным из контейнера хостом. Адрес платформы должен начинаться с `https://`. Адрес `http://` принимается только для локального хоста или с флагом `PLATFORM_ALLOW_INSECURE=true` в закрытой сети. При локальном запуске бот получает обновления через long polling и передаёт их тому же обработчику, что и вебхук в продакшене. Достаточно одного запущенного экземпляра на Telegram-токен.

Даты тренировок и «сегодня» бот считает в часовом поясе тренера. Пояс передаёт кабинет при открытии в браузере. До первого открытия кабинета используется `BOT_DEFAULT_TIME_ZONE`, по умолчанию UTC.

## Работа с подопечными

В главном меню две кнопки — **Подопечные** и **Упражнения**. Откройте **Подопечные** и нажмите **➕ Добавить подопечного** под списком и введите имя и фамилию двумя сообщениями. Нажмите **Сохранить** или **Редактировать**, чтобы указать вес, рост, возраст, пол, цель, заметки и ник Telegram. При сохранении вес и рост попадут в историю замеров за текущую дату.

В разделе **Упражнения** доступен общий каталог администратора. Выберите группу мышц, затем нажмите на название упражнения, чтобы открыть карточку. При заполнении профиля подопечного можно выбрать опубликованную администратором цель.

В карточке подопечного выберите **Тренировки** или **Замеры**. В разделе **Тренировки** нажмите **Записать тренировку**, затем выберите группу мышц и упражнение. Чтобы посмотреть прежние записи, нажмите **Прошедшие тренировки**. В этом списке последние тренировки показаны первыми.

| Выбрано в боте | Сообщение для одного подхода | Результат |
|---|---|---|
| Жим лёжа | `60 10` | 60 кг на 10 повторений |
| Планка | `45с` | 45 секунд без дополнительного веса |
| Удержание гири | `16 30с` | 16 кг в течение 30 секунд |

Несколько подходов можно вставить одним сообщением, каждый с новой строки. Бот создаёт тренировку в PostgreSQL при нажатии **Записать тренировку** и сохраняет принятые подходы сразу. **Готово** заканчивает ввод подходов текущего упражнения. На следующем экране можно добавить ещё одно упражнение, завершить или отменить тренировку либо вернуться в раздел **Тренировки**.

Внутри группы мышц нажмите **↩️ Вернуться к категориям**, чтобы выбрать другую группу. Из списка категорий **↩️ Закрыть тренировку** возвращает в раздел **Тренировки** этого подопечного. Запись остаётся активной. Нажмите **Продолжить тренировку**, чтобы вернуться к тому же шагу.

Нажмите **Завершить тренировку** в разделе **Тренировки** или после ввода подходов. Кнопка **Завершить сразу** сохраняет запись без длительности. Чтобы указать время, нажмите **Указать продолжительность** и выберите 30, 45, 50, 60 или 90 минут. Для другой длительности нажмите **Свой вариант** и отправьте число минут, например `75`. После выбора или ввода времени бот завершит тренировку.

**Отменить тренировку → Да, отменить** удаляет начатую запись вместе с её подходами. После завершения или отмены можно сразу начать новую тренировку.

В разделе **Замеры** первой идёт кнопка **➕ Добавить новый замер**, под ней — замеры по датам. В форме ввода первые две строки занимают **Сохранить** и **Отмена**, ниже расположены показатели, дата и заметка. При редактировании откроются значения за выбранную дату.

## Развёртывание

Сервис разворачивается целиком на одном сервере, вместе с ботами, сайтами и PostgreSQL. Конфигурация и инструкция находятся в `training-collector-deploy`. Бот получает обновления Telegram через long polling: публичный адрес, вебхук и секрет ему не нужны. На один токен должен работать один экземпляр.

Черновик диалога и результаты обработанных шагов хранятся в PostgreSQL за API платформы, поэтому перезапуск бота не обрывает начатую тренировку. Незаконченные диалоги доступны 30 дней после последнего действия, записанные тренировки хранятся независимо. Справочники упражнений и целей в черновик не попадают. После выбора упражнения и после «Ещё упражнение» черновик начинается заново: состояние тренировки уже сохранено на платформе.

Если обработка одного обновления не удалась три раза подряд (`BOT_MAX_UPDATE_ATTEMPTS`), бот отвечает «Произошла ошибка», сбрасывает этот диалог и принимает следующие обновления.
